# Arena artwork slots

Drop files here and the Arena screen picks them up. Nothing needs rebuilding and
no code needs touching.

| file | ground | holds |
|---|---|---|
| `arena_0.png` | Back field | 40 |
| `arena_1.png` | Club gym | 120 |
| `arena_2.png` | Fenced ground | 400 |
| `arena_3.png` | Sports hall | 1,200 |
| `arena_4.png` | Arena | 4,000 |
| `arena_5.png` | National Arena | 12,000 |

**Slot is 520 × 300.** Full colour. Anything at the same proportion works and
looks better on a big screen; anything else is letterboxed rather than
stretched.

The club badge is drawn by the game over the bottom-right, at a quality that
climbs with the level — so leave that corner reasonably clear and do **not**
paint a logo into the artwork.

Full brief, including prompts: `docs/ART.md`.
