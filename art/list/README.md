# The fighting surface

Two slots, and **both must be greyscale** — the fight screen multiplies them by
a mood colour so a Worlds final does not look like a Tuesday. A brown texture
times a brown tint is mud.

| file | size | what |
|---|---|---|
| `surface.png` | 701 × 369 | The list floor, rail to rail, seen from directly overhead |
| `ground.png` | 960 × 540 | What surrounds the list |

Top-down orthographic — no perspective, no horizon. The game draws lane
dividers, set-up lines and a rail border on top, so keep it quiet: anything with
strong pattern competes with the thing the player is actually reading, which is
where five men are standing relative to five other men.
